# Reporting security issues

Send a private report to the repository maintainer. Use GitHub’s **Report a vulnerability**
button under Security when available. If private reporting is unavailable, open an issue
requesting a private contact channel and withhold the technical details until one is arranged.

Include the affected Vibepass commit or version, browser and server versions, the impact, and
steps using a disposable account. Remove vault contents, session data, credentials, and personal
information. The maintainer can use a private advisory to coordinate a fix and publish the
affected versions and mitigation after a release.
